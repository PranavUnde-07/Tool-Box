## 📖 About

ToolBox is a **local-first file processing toolkit** designed to eliminate the privacy concerns of online converters.

Instead of uploading files to unknown cloud servers, ToolBox processes everything **locally** through a backend running on your own machine.

No accounts.

No advertisements.

No cloud storage.

No tracking.

Your files stay under your control.

---

## ✨ Vision

Modern online converters are convenient, but many users ask the same questions:

- Where are my files stored?
- Are my documents deleted after processing?
- Who has access to my data?
- Can I trust the service?

ToolBox solves this problem by running locally.

Files are processed on your own computer and are never permanently stored.

# 🔒 Privacy First

ToolBox follows a **Local Processing Architecture**.

```
User Selects File
        │
        ▼
Frontend Validation
        │
        ▼
Local Backend Processing
        │
        ▼
Processed File
        │
        ▼
Automatic Download
        │
        ▼
Temporary Files Deleted
```

### What this means

- Files never leave your computer.
- No cloud uploads.
- No permanent storage.
- No user accounts.
- No tracking.
- No advertisements.
